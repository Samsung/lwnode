# Security Policy

## Maintenance status

This repository's `main` branch contains the open-source version of lwnode,
which is no longer actively maintained.

The upstream Node.js release used by the open-source version of lwnode has
reached end of life and no longer receives security updates from Node.js.
We no longer provide security updates for that Node.js code in this repository.

The lwnode runtime used in production differs from the code on this
repository's `main` branch and is developed in a separate internal repository.
